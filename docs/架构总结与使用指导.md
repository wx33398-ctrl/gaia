# Gaia Web 服务开发手册（AI 编码代理专用）

> 读者：使用 `com.xwang:gaia-spring-boot-starter:1.0.0`（JDK21 / Spring Boot 3.3.x / MyBatis-Plus 3.5.9）
> 生成 Web 服务代码的 AI 代理。
> 用法：开发新业务前读本文件 → 按 §2 决策 → 按 §3 模板逐层生成 → 按 §6 硬约束自检 → 按 §8 清单交付。
> 所有结论已对源码核对；与 README 冲突处以本文件为准。

---

## 1. 你的心智模型（先建立这个再写代码）

Gaia = **MP 之上的增强层**，不是替代品。三层数据边界 + 固定转换点：

```
请求 ──▶ DTO ──convertToEntity──▶ Entity ──of()──▶ VO ──▶ 响应
        (入参+分页/排序)            (表映射)        (出参)
```

- **Service 只吐 Entity，永远不碰 VO。** VO 转换只发生在 Controller 返回前。
- **DTO→Entity 用 `BeanUtil.copy`（按属性名拷贝）**：所以「要让一个值进 SQL，DTO 和 Entity 必须有同名属性」。
- **查询增强靠 Entity 上的注解**：你在 Entity 字段标 `@Compare/@In/@StartTime/@EndTime/@Relation/@Aggregate`，
  Gaia 注入器增强的 `selectById/selectPage/selectList/selectCount` 会自动拼出对应 SQL，**不写 XML、不写 Wrapper**。
- 框架理念「做增强不做限制」：四件套不满足时，**直接退回原生 MP（`getMapper()`/`lambdaQuery()`/自定义 XML），不要改框架**。

---

## 2. 决策：这个需求怎么实现

```
是标准单表 CRUD / 批量 / 分页 / 简单 left join 联表 / 等值·范围·IN 过滤？
  ├─ 是 → 用四件套 + 注解（§3 模板 + §5 注解映射表）   ← 覆盖 70% 业务
  └─ 否 ↓
     需要复杂多表聚合分页 / UNION / 子查询 / 窗口函数 / 特殊事务编排？
       └─ 是 → 写自定义 Mapper XML + 原生 MP，Service 里直接用 getMapper()/链式 API
              （注意：@Aggregate 只在 selectById 生效，列表/分页聚合必须自定义 SQL）
```

判断准则：**优先用四件套；一旦要绕开它的默认行为，就用 MP，而不是给框架加东西。**

## 3. 生成一个新资源的完整文件集（按顺序，照抄结构）

以资源 `Goods`（表 `goods`）为例。把 `Goods/GoodsEntity/GoodsDTO/GoodsVO/GoodsMapper/GoodsService/GoodsServiceImpl/GoodsController`
整体替换成你的命名。每一层都给出**必须包含**的部分。

### 3.1 Entity（表映射 + 查询辅助字段）

```java
@TableName("goods")
public class GoodsEntity {
    @TableId
    private Long id;
    private String name;
    // ... 真实表列 ...

    // —— 审计六字段（框架不提供 BaseEntity，逐实体声明；填充见 §3.2）——
    @TableField(fill = FieldFill.INSERT)         private LocalDateTime createTime;
    @TableField(fill = FieldFill.INSERT)         private String createBy;
    @TableField(fill = FieldFill.INSERT)         private String createByName;
    @TableField(fill = FieldFill.INSERT_UPDATE)  private LocalDateTime updateTime;
    @TableField(fill = FieldFill.INSERT_UPDATE)  private String updateBy;
    @TableField(fill = FieldFill.INSERT_UPDATE)  private String updateByName;

    // —— 查询辅助字段：exist=false + gaia 注解；每个都要在 DTO 里有同名字段 ——
    @TableField(exist = false) @Compare(column = "name", operate = "like") private String nameLike;  // like 自动包 %kw%；leftLike 自动 %kw、rightLike 自动 kw%
    @TableField(exist = false) @StartTime(column = "create_time", type = "datetime") private LocalDateTime startTime;
    @TableField(exist = false) @EndTime(column = "create_time", type = "datetime") private LocalDateTime endTime;
    @TableField(exist = false) @In(column = "status") private List<Integer> statusList;
    // getter/setter 省略（用 Lombok @Data 即可）
}
```

### 3.2 MetaObjectHandler（审计字段填充，全应用一个，业务自己实现）

```java
@Component
public class AppMetaObjectHandler implements MetaObjectHandler {
    @Override public void insertFill(MetaObject m) {
        strictInsertFill(m, "createTime", LocalDateTime.class, LocalDateTime.now());
        strictInsertFill(m, "createBy", String.class, currentUsername());   // 取自你的登录上下文
        // createByName / update* 同理
    }
    @Override public void updateFill(MetaObject m) { /* update 系字段 */ }
}
```
> 框架不绑定用户来源，`createBy` 怎么取是你的事。

### 3.3 DTO（入参 + 分页排序 + 查询辅助字段同名）

```java
public class GoodsDTO extends BaseDTO<GoodsDTO> {   // 自指泛型
    private Long id;
    private String name;
    // 查询辅助字段：与 Entity 同名，否则值进不了 SQL
    private String nameLike;
    private LocalDateTime startTime;
    private LocalDateTime endTime;
    private List<Integer> statusList;
    // getter/setter
}
```
> `BaseDTO` 已内置 `current/size/ascs/descs/orders/maxLimit`，**不要再自己声明分页字段**。

### 3.4 VO（出参 + 派生字段回调）

```java
public class GoodsVO implements BaseVO<GoodsVO> {   // 自指泛型
    private Long id;
    private String name;
    private Integer status;
    private String statusName;            // 派生字段
    @Override public void afterPropertySet() {       // of() 拷贝后回调
        this.statusName = StatusEnum.of(this.status).getName();
    }
    // getter/setter
}
```

### 3.5 Mapper

```java
@Mapper
public interface GoodsMapper extends BaseMapper<GoodsEntity> {}
```

### 3.6 Service 接口（BaseService 必须是第一个父接口）

```java
public interface GoodsService extends BaseService<GoodsEntity, GoodsDTO> {}
```

### 3.7 Service 实现（Gaia 接口必须是第一个 implements；覆写 getMapper）

```java
@Service
public class GoodsServiceImpl extends ServiceImpl<GoodsMapper, GoodsEntity> implements GoodsService {
    @Override public BaseMapper<GoodsEntity> getMapper() { return this.baseMapper; }
    // 需要按场景改写转换时覆写 convertToEntityForAdd/Query/Modify
    // ForQuery 对 queryPage/queryList/queryCount/queryOne/removeEntity(dto) 全部生效（条件天然一致）
}
```

### 3.8 Controller（直接子类给三泛型；方法要自己加映射注解才暴露）

```java
@RestController
@RequestMapping("/goods")
public class GoodsController extends BaseController<GoodsEntity, GoodsDTO, GoodsVO> {
    @Autowired private GoodsService goodsService;
    @Override protected BaseService<GoodsEntity, GoodsDTO> getService() { return goodsService; }

    // ⚠️ 父类 8 个方法没有 @Mapping 注解，必须在此覆写并加注解才会成为 HTTP 端点
    @PostMapping("/add")
    @Override public R<Object> addEntity(@RequestBody GoodsDTO dto) { return super.addEntity(dto); }

    @PostMapping("/page")
    @Override public R<IPage<GoodsVO>> queryPage(@RequestBody GoodsDTO dto) { return super.queryPage(dto); }

    @GetMapping("/detail")
    @Override public R<GoodsVO> queryDetail(@RequestParam Serializable id) { return super.queryDetail(id); }

    // 其余 modifyEntity/removeEntity/removeBatch/addBatch/modifyBatch 同理按需暴露
}
```

## 4. 四件套给你的能力（直接调用，不要重写）

### 4.1 Controller 八个方法（返回都是 `R`，`code==0` 成功）

| 方法 | 入参 | 返回 | 失败码 |
|---|---|---|---|
| `addEntity(dto)` | D | `R<Object>` 主键 | — |
| `addBatch(Collection<D>)` | List | `R<Integer>` size | — |
| `modifyEntity(dto)` | D（含主键） | `R<Void>` | 10102 |
| `modifyBatch(List<D>)` | List | `R<Integer>` size | — |
| `removeEntity(id)` | id | `R<Void>` | 10103 |
| `removeBatch(idList)` | List | `R<Integer>` 删除数 | 0 条→10103 |
| `queryDetail(id)` | id | `R<V>`（已转 VO） | 查不到→10104 |
| `queryPage(dto)` | D | `R<IPage<V>>`（records 已转 VO） | — |

辅助：`convertToEntity(D)`、`getCacheKey(dto[,str])`（给分页结果做缓存 key）、`getRequest()/getResponse()`。

### 4.2 Service 常用（DTO 进，Entity/主键出）

`addEntity/modifyEntity/removeEntity(id|dto)/removeBatch/queryDetail/queryOne/queryCount/queryPage/queryList`。
批量与链式（MP IService 兼容区，免导 MP）：`addBatch/updateBatchById/saveOrUpdateBatch/saveOrUpdate/remove/update/
listByIds/listByMap/list/listMaps/getOne/count/page` + `query()/lambdaQuery()/update()/lambdaUpdate()`。

`queryPage/queryList` 带 `Consumer<QueryWrapper<E>>` 重载——**注解不够用时在这里追加原生条件**：
```java
goodsService.queryPage(dto, q -> q.isNotNull("category_id").groupBy("type"));
```

### 4.3 R 用法

- 普通成功：`R.success(data)`；空成功：`R.success()`。
- 分页：`R.success(page, vo -> ...)` 自动包成 `{total,pages,size,current,records}`（前端读 `data.records`/`data.total`；空页 `records` 恒为 `[]` 不为 null）。
- 列表转换：`R.success(list, func[, consumer])`。
- 失败：`R.failure(BusinessException.Status.XXX[, msg])`。

## 5. 查询需求 → 注解映射表（写在 Entity 辅助字段 + DTO 同名字段）

| 你想要的 SQL | 在 Entity 上写（字段标 `@TableField(exist=false)`） | DTO 加同名字段 |
|---|---|---|
| `name = ?` | 直接真实列即可（MP 默认等值），或用 `@Compare(column="name", operate="=")` | `String name` |
| `name LIKE '%kw%'` | `@Compare(column="name", operate="like")`（框架自动包 `%kw%`） | `String nameLike` |
| `name LIKE '%kw'` | `@Compare(column="name", operate="leftLike")`（自动包 `%kw`） | `String nameLeftLike` |
| `name LIKE 'kw%'` | `@Compare(column="name", operate="rightLike")`（自动包 `kw%`） | `String nameRightLike` |
| `amount >= ?` | `@Compare(column="amount", operate=">=")` | `BigDecimal minAmount` |
| `status IN (?)` | `@In(column="status")` | `List<Integer> statusList` |
| `id NOT IN (?)` | `@In(column="id", type=1)` | `List<Long> excludeIds` |
| `create_time >= ?` | `@StartTime(column="create_time", type="datetime")` | `LocalDateTime startTime` |
| `create_time <= ?` | `@EndTime(column="create_time", type="datetime")` | `LocalDateTime endTime` |
| 联表取列 + 作为条件 | `@Relation(condition="left join dept d on d.id=t.dept_id", columnStr="d.dept_name deptName", wherePrefix="d")` | `String deptName` |
| 子查询计数列 | `@Aggregate("select count(1) from item i where i.goods_id=t.id")` | （**仅 selectById 生效**；列表/分页要聚合列→自定义 SQL） |

排序：前端传 `ascs=sort_order,id` / `descs=id`（BaseDTO 字段），Gaia 自动校验注入 + 加 `t.` 前缀。
逻辑删除：用 MP `@TableLogic`，Gaia 增强 SQL 自动带 `t.del_flag='0'`。

## 6. 硬约束（生成代码后逐条自检，违反则代码跑不起来或埋雷）

1. **端点必须自己加注解**：父类 8 个方法无 `@XxxMapping`，子类不覆写加注解 = 没有 URL。入参 `@RequestBody/@RequestParam` 也由你加。
2. **查询辅助字段 DTO 与 Entity 都要有、同名**：只放 Entity 前端传不进；只放 DTO 进不了 SQL。
3. **泛型必须直接子类具体化**：`Controller extends BaseController<E,D,V>` 三泛型写全；
   `Service 接口` 以 `BaseService<E,D>` 为第一个父接口；`ServiceImpl` 以该接口为第一个 implements。错序→泛型解析失败。
4. **`@Relation` 的 `condition`/`columnStr` 只能写代码常量，禁止来自请求参数**（原样拼 SQL，注入面）。`type` 仅 `0` 实现。
5. **`@Compare.operate` 不要用裸 `<`/`<=`**（破坏 MyBatis XML）；小于比较用 `@EndTime` 或 `operate="&lt;"`。
6. **`@Aggregate` 只在 `selectById` 生效**（`selectPage`/`selectList`/`selectCount`/`*ByScope` 一律不拼：关联子查询按结果行执行，N 行 = N 次子查询）；列表/分页要聚合列→自定义 SQL 一次 group by join。
7. **JVM 必加** `--add-opens=java.base/java.lang=ALL-UNNAMED`（mica CGLIB 拷贝），运行和 surefire 都要。
8. **不要在 DTO 重复声明分页字段**（`current/size/ascs/descs/orders` 已在 BaseDTO）。
9. **`clearCache()` 不会被写操作自动调用**：要写后失效缓存，自己在写路径显式调。
10. **建议宿主配 Long→String**（`ToStringSerializer(Long.class)`），否则前端 Long 精度丢失。
11. **框架不带全局异常处理器**：`BusinessException` 抛出后需宿主 `@RestControllerAdvice` 转 `R.failure`。
12. 框架**不提供 BaseEntity**：审计字段逐实体写。

## 7. 缓存（可选，按需生成）

- 缓存名派生：`{prefix}_{类名去 Entity 后缀首字母小写}`（`GoodsLimitEntity`→`demo_goodsLimit`），用 `CacheTypeScanner`。
- TTL 分组：字典/配置实体标 `@TableType(TableTypeEnum.CONFIG)`（长 TTL），其余默认 `BUSINESS`（短 TTL）。
  `RedisCacheConfig` 用 `scanConfigCachesByClassName/scanBusinessCachesByClassName` 批量配 TTL。
- 一致性检查器：仅当宿主有 `CacheManager` 且配了 `gaia.cache.name-prefix` 才注册；启动期比对 `@Cacheable` 等引用的缓存名。

```yaml
gaia:
  cache:
    name-prefix: demo_        # 不设则不注册检查器
    consistency-checker:
      enabled: true
```

## 8. 交付前清单（AI 自检，全绿才算完成）

- [ ] Entity：`@TableName`+`@TableId`+审计六字段+查询辅助字段（`exist=false`+注解）。
- [ ] DTO：`extends BaseDTO<自身>`；查询辅助字段与 Entity 同名；未重复声明分页字段。
- [ ] VO：`implements BaseVO<自身>`；派生字段写在 `afterPropertySet()`。
- [ ] Mapper：`extends BaseMapper<Entity>` + `@Mapper`。
- [ ] Service 接口：`extends BaseService<Entity,DTO>`（第一父接口）。
- [ ] ServiceImpl：`extends ServiceImpl<Mapper,Entity> implements XxxService`（第一 implements）+ 覆写 `getMapper()`。
- [ ] Controller：`extends BaseController<Entity,DTO,VO>` + 实现 `getService()` + **要暴露的方法都加了 `@XxxMapping`**。
- [ ] 应用级：`MetaObjectHandler` 已实现；JVM 加 `--add-opens`；（建议）Long→String；（按需）`@RestControllerAdvice`。
- [ ] 没有把请求参数拼进 `@Relation`；`@Compare` 无裸 `<`；`@Aggregate` 只用在详情（selectById），列表/分页聚合走自定义 SQL。
- [ ] 复杂查询走自定义 SQL 而非硬塞注解。

## 10. 框架不含（别去找/别自己造轮子前先确认边界）
